# RePak — agent notes

Human overview: `README.md`. Pipeline pairing: RSX extract → this packer.

Writes **S21-native** asset versions. `"dedi": true` routes mdl_ / aseq / arig
to **S3** versions.

## Build

`RePak.sln`, Release x64, toolset **v145**. Output: `bin/Release/repak.exe`.

```
repak <buildMap.json | build_list.json>
repak -pakguid <string>
repak -compress <pak> [level] [workers]
repak -decompress <pak>
```

## Manifest

```json
{ "version": 8, "name": "map", "assetsDir": "./assets/", "outputDir": "./out/",
  "headerFlags": 32, "files": [ { "_type": "mdl_", "_path": "mdl/..." } ] }
```

- `_path` is the canonical asset name. `$guid` pins the GUID; else StringToGuid.
- Build list: top-level `{ "paks": [ "a.json", "b.json" ], "dedi": true }`.
  `dedi` / `keepClientOnly` / `outputDir` are read from the **list**, not
  the per-pak file. Per-pak `assetsDir` is relative to the list’s directory.

## S21 writers (default)

| 4cc | ver | notes |
|-----|-----|--------|
| mdl_ | 17 | field-relative LOD groups; rewrite compressed VG offsets to raw `.vg` |
| aseq | 11 | `.rseq` blob is a **v16 seqdesc** (FIX_OFFSET), not v7 |
| arig | 6 | u16 seqCount @ 0x12; `.rrig` is v16 skeleton, no IDST |
| matl | 23 | WriteToBuffer gate is `>= 15` |
| shdr | 15 | child shaders: `$parentShader`, no CPU |
| shds | 12 | VS/PS GUIDs @ 0x40 / 0x48 |
| txtr | 10 | synth `$hdrTail` when streamed mips omit it |
| txtx | 2 | raw container |
| uiia | 2 | raw `[hdr][tiles]`, not a decoded PNG |
| rmap | 4 | 104B stub; geometry is in wrap/BSP |
| wrap | 7 | BSP lump wrapper; align 64, 256 for lump `0x69` |
| efct | 16 | `.efct_def` + child/asset GUID sidecars |
| rui | — | RUIP v2 `pointerFixups` when `defaultStringOffsets` empty |

`"dedi": true`: mdl_ **v10**, aseq **v7**, arig **v4**; skip VG/materials.
Dedi 4cc universe is mdl_ aseq arig stgs stlt dtbl txls Ptch. Dedi paks are
**zstd** (`compressLevel` 6), not oodle.

## Do

- Extract with RSX in **re-packable** mode (`-exportfullpaths`, materials
  `--texturenames guid` or `stored`). imgui.ini `[AssetSettings]` is **GUI
  only**; `-nogui` uses code defaults.
- **Asset order is load-bearing.** Models first, then
  dtbl/shdr/shds/txan/txtr/txtx/matl/aseq/arig/rmap/uiia. Wrong order AVs
  in pak-load pointer relocation.
- Header pages are append-only. Do not back-fill a late header into an
  earlier page.
- `Pak file consistency error` = a guidDesc to a GUID not in the loaded
  registry (including `0x0`). Fix refs; do not patch the client.
- StringToGuid: textures hash **with** `.rpak`; named matl/mdl **without**.
- uiia on-disk name can be doubled (`ui_image/ui_image/...`). Open path is
  `assetsDir + assetName`.
- Per-map starpak name (`<map>.starpak`). A shared name regenerated by one
  map clobbers every other map’s offsets.

## Do not

- Use synthetic material texture paths (default RSX text names). They
  StringToGuid to the wrong GUID.
- Index guid-mode materials by **filename stem**. Two materials can share a
  stem. Match by full relative path.
- Treat RSX `--exporttypes uiia` PNG/DDS as the RePak input. Need the raw
  `.uiia` container.
- Pack a second copy of an arig that already lives in `common.rpak`.
- Run a per-pak manifest from the wrong cwd (assetsDir resolves from the
  build-list directory).
